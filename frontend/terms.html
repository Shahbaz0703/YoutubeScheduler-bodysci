⚡ 3. Description of Software & Service

ShortsScheduler is an automated personal scheduling tool utilizing:

  • Node.js scripts for scanning video files and interacting with the YouTube Data API v3.
  • Git Large File Storage (LFS) selective pulling mechanisms to manage media files efficiently.
  • GitHub Actions automated cron workflows for scheduled, sequential video publication.
  • Static GitHub Pages dashboard for monitoring schedule progress, upload status, and video queue states.

The software is self-hosted and client-operated. No centralized hosted cloud service, proxy server, or SaaS backend is provided or maintained by third parties.
